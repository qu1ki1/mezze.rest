# Меззе — сайт ресторана турецкой кухни (Тюмень)

Статический сайт без сборки: `index.html`, `style.css`, `script.js`, папка `img/`, `menu.pdf`.

Локально: `python -m http.server 8080` в папке проекта, затем http://localhost:8080

Анимации: GSAP + ScrollTrigger, Lenis, SplitType (подключаются с CDN).
Данные меню — массив `MENU` в начале `script.js`.

## Исходники
В папке `source/` лежат сжатые копии исходных материалов: фото (`photo/`, `bar/`), логотипы (`logo/`) и `menu-hq.pdf` (меню в хорошем качестве, 10 МБ). Оригиналы (в т.ч. PDF на 138 МБ) хранятся локально — GitHub не принимает файлы больше 100 МБ.
